# Pass the Punch

A chaotic 3D party brawler with local bots, online multiplayer, token-powered punches, and ghost abilities.

## Requirements

- Node.js 24.22.2 or newer in the Node.js 24 LTS line
- npm

## Run locally

```powershell
npm install
npm run dev
```

Open the address printed by the server (by default, `http://localhost:3000`). No API keys or PHP runtime are required.

## Commands

- `npm run dev` — start the game server and development client
- `npm run build` — build the production client
- `npm start` — start the server in production mode after building
- `npm run lint` — type-check the project
